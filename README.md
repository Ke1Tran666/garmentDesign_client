# Garment Design Client

A modern, responsive web application for designing and managing garment designs. Built with React, Vite, and Tailwind CSS.

## Overview

Garment Design Client is a frontend application that provides an intuitive interface for creating, editing, and managing garment designs. The application leverages modern web technologies for optimal performance and user experience.

## Tech Stack

- **React 19** - UI library for building interactive interfaces
- **Vite** - Lightning-fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework for styling
- **Lucide React** - Beautiful, consistent SVG icon library
- **ESLint** - Code quality and style enforcement

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Install dependencies:

```bash
npm install
# or
yarn install
```

### Development

Start the development server:

```bash
npm run dev
# or
yarn dev
```

The application will be available at `http://localhost:5173` (or another port if 5173 is in use).

### Building

Create an optimized production build:

```bash
npm run build
# or
yarn build
```

The built files will be in the `dist/` directory.

### Preview

Preview the production build locally:

```bash
npm run preview
# or
yarn preview
```

### Linting

Check and enforce code quality:

```bash
npm run lint
# or
yarn lint
```

## Project Structure

